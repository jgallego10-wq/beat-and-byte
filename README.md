# Beat&bit - Mi primera web Estática

Sitio web desarrollado para el taller práctico de Técnicas de Modelado de Software.

##Características del Sitio
- **Temática:** Música y Desarrollo de Software.
- **Estructura:** 5 secciones semánticas (Header, Perfil, Noticias/Blog, Top 3 de Álbumes y Footer en 2 columnas). 
- **Tecnologías:** HTML5 y CSS3 responsivo. 
- **Despliegue:** Publicado a través de GitHub Pages.
